# SDO Collections Website

A responsive GitHub Pages-ready website for SDO Collections. The original logo image supplied by the user is included unchanged at `assets/sdo-collections-original-logo.png`.

## Files
- `index.html` — website structure and content
- `styles.css` — responsive design and styles
- `script.js` — mobile navigation and WhatsApp enquiry links
- `assets/sdo-collections-original-logo.png` — supplied logo image, unedited

## Before publishing
1. Open `script.js`.
2. Replace `2340000000000` in `WHATSAPP_NUMBER` with the business WhatsApp number. For a Nigerian number, use country code 234 and omit the leading 0, plus sign, spaces and dashes.
3. Review the wording and product categories. Add real product photos, descriptions and prices when available.
4. Do not remove or replace the original logo asset if you want the exact supplied image retained.

## Publish with GitHub Pages
1. Sign in at https://github.com/
2. Create a new public repository, for example `sdo-collections`.
3. Upload the contents of this ZIP (the files inside the folder, not the ZIP itself) so `index.html` is at the repository root.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then save.
7. Wait a few minutes. GitHub will show the public website address in the Pages section.

## Notes
- GitHub Pages can host this static catalogue website at no hosting charge, subject to GitHub's current terms.
- This version does not process online payments or maintain a shopping cart. Customers enquire through WhatsApp once the correct number is configured.
- The hero and product illustrations are CSS artwork, not product photographs. Replace them with genuine product images for a more accurate shop catalogue.
- The original logo is displayed as the uploaded image; it has not been redrawn or recoloured.
